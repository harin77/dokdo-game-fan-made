# ⛵ DOKDO — Fan Revival

A fan-made revival of **DOKDO**, a mobile sailing and pirate game that shut down years ago.
I loved it as a kid, so I brought it back to life. It now runs on **modern 64-bit Android phones** and works **fully offline**.

> **Fan project — not affiliated with the original developer.**
> DOKDO was originally made by **Zzoo**. All game art, music, and the DOKDO name belong to their owners.
> This is a free, non-commercial revival for players who miss the game. If you own the rights and want it taken down, contact me and I'll remove it.

## 📱 How to install

1. Download `DOKDO.apk` from **[Releases](../../releases)**.
2. If the **old DOKDO** is still on your phone, **uninstall it first**. Android won't install over it.
3. Open the APK. If your phone asks, allow **"Install unknown apps"** for your browser or file manager.
4. Play! ⛵

---

## ✨ What's new in this revival

- 📲 **Works on new phones:** rebuilt as a 64-bit app, so phones that can't open old 32-bit apps can run it
- 🌐 **Fully offline:** no account, no internet, no dead servers
- 🎁 **Everything free:** every paid store item is free. Just tap it and it's yours
- 🚫 **No ads:** ad-reward buttons give the reward instantly
- 🔍 **Better camera:** closer view, and you can **pinch to zoom** (it remembers your zoom)
- 🌊 **Water and effects fixed:** the water and particle effects work again
- 🏆 **Local leaderboard:** your best scores are saved on your phone
- 💾 **Backup save:** saves a backup file on your phone instead of the old cloud save

## 🐞 Found a bug? Send me your log

The game saves a log file every time you play, so problems are easy to fix.

**Where to find it:** `Android/data/com.zzoo.dokdo/files/logs/`

On Android 11 and newer, most file managers can't open `Android/data`. Connect your phone to a PC with USB and copy the newest `dokdo_*.txt` file from there.

**Send it to me:**
- Telegram: **[@its_me_harin77](https://t.me/its_me_harin77)**
- Or open an **[Issue](../../issues)** here on GitHub

Please tell me what you were doing when the problem happened, and your phone model.
